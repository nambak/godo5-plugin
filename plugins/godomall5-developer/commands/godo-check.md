지정된 파일 또는 디렉토리의 고도몰5 자동패치 호환성을 정적으로 검사한다.

대상 경로: `$ARGUMENTS` (미지정 시 `module/` 디렉토리 전체)

> **이 커맨드의 범위**: 이 도구는 정규식·grep·파일 메타정보로 **자동 검출 가능한 8개 항목**만 검사한다. 마스터 체크리스트는 12개이며, 자동 검출이 불가능한 항목(어드민 스킨 미러링, `parent::index()` exit 동작, Logger 채널 정합성, 관리자 UI 사전 확인 등)은 본 커맨드 결과만으로는 확인되지 않는다.
>
> **마스터 체크리스트(12항목) 출처**: `references/project-template.md`의 "오버라이드/수정 전 체크리스트" 섹션. 이 명령 실행 후 통과했더라도 마스터 체크리스트 12개 전체에 대한 코드 리뷰가 별도로 필요하다.

자동 검사 항목 (8개):

1. **Bundle 수정 여부** — Bundle/ 디렉토리 내 파일이 수정되었는지 확인 (git diff 또는 파일 타임스탬프)
2. **상속 패턴** — module/ 내 클래스가 `extends \Bundle\...` 형태로 올바르게 상속하는지 확인
3. **App::load() 사용** — `new \Bundle\...` 직접 생성 코드가 없는지 확인
4. **라이선스 헤더** — 모든 PHP 파일에 NHN godo 라이선스 헤더가 있는지 확인
5. **바인드 쿼리** — SQL 문자열 직접 삽입 패턴이 없는지 확인 (정규식으로 검사)
6. **금지 함수** — `eval()`, `extract()`, `var_dump()`, `print_r()` 사용 여부
7. **금지 접두사** — `es_`, `zz_` 접두사로 시작하는 커스텀 테이블/컬럼 없는지 확인
8. **파일 길이** — 500줄 초과 파일 경고

자동 검출 불가 — 수동 검토 필요 (마스터 체크리스트의 나머지 4개):

- **보호 파일 미접촉**: `Asset/Admin/` 전체, `admin/gd_share/`, `config/app/system_version.php`, `config/plus_shop_info.php`, `route.php`, `system/<버전>/`
- **어드민 스킨 미러링**: `Asset/Admin/<경로>` 대신 `admin/<경로>`에서 작업하는가
- **`parent::index()` exit 확인**: 부모 컨트롤러가 `index()` 안에서 `exit()`를 호출하는지 소스 확인
- **Logger 채널 정합성**: `\Logger::channel('userLog')->debug(...)` 외의 채널/레벨은 로그가 남지 않음 — 정적 grep으로는 정합성 판단 어려움
- **관리자 UI 사전 확인**: 코드 수정 전에 관리자 설정 메뉴에 동일 기능이 있는지 확인

결과를 표 형식으로 정리하여 보고한다:
- 통과 항목은 ✅
- 위반 항목은 ❌ + 파일 경로 + 구체적 위치
- 개선 권장 항목은 ⚠️

마지막에 자동 검사 8개 기준 호환성 점수(%)와 함께, 수동 검토가 필요한 4개 항목을 별도로 안내한다.
